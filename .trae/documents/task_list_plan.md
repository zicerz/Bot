# 任务列表展示方案设计

## 一、需求分析

用户希望在执行 `--list` 命令时，不仅显示任务配置列表，还能展示当日任务的完成情况，要求视觉效果良好。

### 当前功能
- 显示任务名称、webhook配置、执行时间点
- 显示备份配置信息

### 新增需求
- 显示当日每个时间点任务的执行状态（成功/失败/未执行）
- 统计信息展示（总任务数、已执行数、成功率等）
- 良好的视觉效果（颜色输出）

### 4.1 数据存储

创建执行记录文件 `execution_log.json`，格式如下：

```json
{
  "2026-06-03": {
    "tasks": {
      "0": {
        "executions": {
          "08:35": "success",
          "10:35": "success", 
          "12:35": "success",
          "14:35": "failed"
        }
      },
      "1": {
        "executions": {
          "08:35": "success",
          "10:35": "success",
          "12:35": "success",
          "14:35": "success"
        }
      }
    }
  }
}
```

### 4.3 颜色代码定义

```python
# ANSI 颜色代码
```

### 4.4 执行记录写入时机

## 五、方案优势

1. **视觉清晰**：进度条直观展示完成比例
2. **信息完整**：时间线显示每个时间点状态
3. **颜色区分**：不同状态使用不同颜色，一目了然
4. **格式紧凑**：不占用过多屏幕空间
